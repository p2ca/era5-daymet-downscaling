CorrDiff

Overall structure Deterministic regression + conditional residual diffusion
Regressor UNet; 15 → 3; base 64; predicts conditional mean μ
Diffusion target r = truth − μ
Generator input 21 = noisy residual 3 + condition 15 + μ 3
Generator output 3-channel residual; final prediction μ + sampled residual
Generator architecture 2-level UNet; base 64; same residual, downsampling, upsampling, and skip blocks as UNet
Time embedding Sinusoidal embedding; dimension 128; MLP injection into every residual block
Spatial mode 192×192 training and sampling tiles; 25% overlap with feathered blending
EDM parameters σdata=0.3603; σmin=0.002; σmax=80; ρ=7; Pmean=−1.2; Pstd=1.2
Sampling Stochastic second-order EDM; 18 steps; 16 members
Parameters Regressor ≈1.6M + generator ≈1.7M = ≈3.3M
Batch size 16/rank × 8 ranks = 128 global
Epochs Generator 80, best checkpoint at 73; regressor reused UNet best checkpoint at 11
Optimization steps Generator 500/epoch, 40,000 total; regressor not retrained
